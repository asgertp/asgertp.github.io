Privacy Policy

ClipMaker · Last updated 18 November 2026 (rev. 2)

ClipMaker is a private tool operated by a single person (the "owner") to publish videos to the owner's own YouTube channel and Instagram account. It has no other users and is not available to the public.

YouTube API Services

ClipMaker uses YouTube API Services. By using ClipMaker you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Data we access

When the owner connects their own Google account, ClipMaker requests these YouTube permissions:

  • youtube.upload – to upload videos the owner has produced to the owner's channel.
  • youtube.readonly – to read view and like counts of the owner's own videos and to look up public lists of popular videos.

When the owner connects their own Instagram professional account, ClipMaker uses Meta's Instagram API to publish Reels and read view and like counts for the owner's own posts.

How data is used and stored

  • Access tokens are stored only on the owner's own computer, and are used only to perform the actions above.
  • Video statistics are stored locally and used only to decide which kinds of videos to make next.
  • ClipMaker does not collect, store or process personal data about viewers or any other people.
  • No data is sold, shared with third parties, or used for advertising.

Data retention and deletion

  • View and like counts obtained from the YouTube API are refreshed daily and automatically deleted after at most 30 days.
  • Lists of popular public videos (titles and view counts) are replaced every day and are not kept longer.
  • OAuth tokens are kept only until access is revoked or the local data folder is deleted.

Cookies and device storage

ClipMaker does not place cookies and does not store or access information on any visitor's or viewer's device. Data is stored only on the owner's own computer, as described above.

Google API Services User Data Policy

ClipMaker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. ClipMaker uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time via the Google security settings page at https://security.google.com/settings/security/permissions (or myaccount.google.com/permissions), and in the Instagram/Facebook app settings (Meta). After access is revoked, all stored YouTube data is deleted from the local ClipMaker data folder within 7 days; deleting that folder removes all tokens and statistics immediately.
